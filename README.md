# Portfolio — Dharun Kanagasabai

A single-page responsive portfolio site. No build step, no dependencies — just `index.html`.

## Before you deploy

1. **Add your résumé PDF.** Drop a file named `resume.pdf` into this same folder (next to `index.html`). The "Download Résumé" button already points to it.
2. **Fill in real project links.** Open `index.html`, search for `href="#"` inside each `.card-links` block, and replace with your actual GitHub repo URLs (and live demo URLs where you have them).
3. **Double check contact details** — email, phone, and LinkedIn URL are in the Contact section near the bottom of the file.
